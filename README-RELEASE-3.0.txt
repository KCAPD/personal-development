KCA Personal Development — Release 3.0 Prototype
YEAR 3 + COURAGE ONLY

WHAT THIS RELEASE DOES
- Keeps the existing website design and all existing interactions.
- When Year 3 is selected AND Connor Courage is clicked, the existing modal expands.
- Adds the exact six Year 3 Courage observable behaviours from the Journey Journal.
- Each observable behaviour opens as an accordion.
- Shows Signature Experiences, Across our Curriculum, Everyday School Life and Why this matters.
- Mobile design is intentionally compact; experience chips stay in two columns.
- All other years and all other value cards behave exactly as before.

UPLOAD / REPLACE ONLY

- style.css
- script.js

NO IMAGE CHANGES ARE REQUIRED.
